## Features

- **Animated hero** with floating blobs and a typewriter effect cycling through roles
- **Glassmorphism cards** with hover lift and glow effects
- **Scroll-triggered fade-in** animations for every card and section
- **Active nav link highlighting** as you scroll
- **Responsive** — mobile hamburger menu, fluid grid layouts
- **Dark theme** with a purple/violet gradient accent palette
- **Zero dependencies** — no React, no Tailwind, no bundler needed

---

## Tech Stack

```
HTML5 · CSS3 (custom properties, grid, animations) · Vanilla JS
Google Fonts: Inter + Space Grotesk
```

## Getting Started

Clone and open locally — no build step required:

```bash
git clone https://github.com/Vaishnavipawarr/TEst.git
cd TEst
open index.html   # macOS
xdg-open index.html   # Linux
```

---

## Deploying via GitHub Pages

1. Go to your repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `(root)`
4. Click **Save** — your site will be live at `https://vaishnavipawarr.github.io/TEst`
